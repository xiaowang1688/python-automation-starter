# Remote Collaboration & Work Samples

## Target roles
- Python Automation Engineer: script-driven business processes, API checks, scheduled jobs
- QA Automation / API Test Engineer: reproducible test scenarios, assertion-based checks, CI reports
- Automation Contractor: short, clearly scoped deliverables with test evidence and written handover

## How I work
1. Clarify inputs, outputs, edge cases, acceptance tests, and delivery date through written requirements.
2. Build a minimal reproducer against safe sample data; avoid collecting credentials.
3. Implement small, reviewable changes with structured outputs and explicit failure behavior.
4. Add offline tests and CI evidence.
5. Deliver README usage instructions, sample outputs, limitations, and handover notes.

## Communication and availability
- Based in Mainland China; standard time UTC+8.
- Chinese-first; translation-assisted English written communication.
- Favor asynchronous GitHub Issues, pull requests, code review notes, and checklists.
- Time-zone overlap, workload and spoken meeting requirements should be agreed for each engagement.
- No claim is made here of fluent spoken English, a specific paid-employment history, or an international employer.
